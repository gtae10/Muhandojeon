# AI 2 — Clienteling / LLM

담당: AI 2

## 역할
- 상담 AI (대화형 에이전트)
- 상품·브랜드 데이터 RAG (헤리티지 스토리, 제품 스펙, 옴니채널 재고 정보)
- 망설임 유형별 응답 전략 생성 (AI1의 intentType을 입력으로 받음)
- 톤 원칙: 쿠폰/푸시가 아닌 "부티크 어드바이저의 한마디"

## 백엔드/프론트로 넘길 응답 형식 (초안)
```json
{ "reply": "13인치 노트북까지 들어가고..." }
```

## 확정 필요
- 응답을 일반 JSON으로 줄지, 스트리밍(SSE)으로 줄지 → 프론트(풀스택1)와 조율
